Сгенерируй код для одной задачи по изменению Python-кода.

Верни только валидный JSON, соответствующий требуемому контракту.

Требования к языку:
- Все текстовые значения JSON пиши на русском языке.
- Если в коде появляется новый текст ошибки, используй русский язык.
- Не смешивай русский и английский язык в текстовых значениях.
- Если создаешь или меняешь ValueError, текст ошибки должен быть на русском языке.
- Если в итоговом коде останется новый английский текст ошибки, ответ считается некорректным.

Требования к полю operation:
- Для изменения существующей функции используй только значение "replace_function".
- Для добавления новой функции используй только значение "add_function".
- Не используй значение "modify_function" в ответе coder.

Требования к изменению:
- Меняй только один указанный target.
- Не добавляй внешние зависимости.
- Не делай лишний рефакторинг.
- Сохраняй стиль существующего Python-кода.
- Если operation=modify_function, верни полную обновленную функцию, но в JSON укажи operation="replace_function".
- Если operation=add_function, верни полную новую функцию.
- Если operation=add_function, добавь короткий docstring на русском языке сразу после сигнатуры новой функции.

Параметры задачи:
- operation: {operation}
- target_file: {target_file}
- target_symbol: {target_symbol}
- insert_after: {insert_after}
- reference_symbol: {reference_symbol}
