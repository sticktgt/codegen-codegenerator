Подготовь краткий план генерации pytest-теста.

Верни только валидный JSON.

Обязательные поля JSON:
- target_symbol
- test_intent
- must_use_symbols
- avoid

Не придумывай отсутствующие import path, поля, методы, аргументы конструктора и атрибуты.
Опирайся только на явно видимый контекст.
Сохраняй явно указанные пользователем имена методов, функций, классов, параметров и форматы ожидаемого результата; не заменяй их именами из сгенерированного кода, если они противоречат запросу.
План должен быть коротким и полезным именно для генерации одного тестового файла.
Если operation=insert_after_symbol, target_symbol уже указывает на новый symbol для тестирования, а не на anchor-symbol.
Если insert_scope=class_body, target_symbol указывает на новый метод; тест должен использовать parent class и вызывать метод через экземпляр.
